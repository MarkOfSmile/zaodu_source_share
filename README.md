# 早读语音评测系统（本地 / 公网双形态）

把「老师听群里几十条语音、逐个纠正读音、出报告」这件事做成一个可跑通闭环的应用。
**零 pip 依赖**：Python 3.9+ 标准库。本机额外用 macOS 的 `say` / `afconvert` / Chrome；
部署到托管环境时缺失这些工具会自动降级，不会静默失败。

## 本地运行

```bash
cd zaodu
bash run.sh          # 默认 8787 端口，绑定 0.0.0.0
# 或 python3 server.py 9000
# 或 PORT=8080 TEACHER_KEY=你的口令 python3 server.py
```

浏览器打开 `http://127.0.0.1:8787/`。手机访问同一 Wi-Fi 时直接打开 `http://<电脑局域网IP>:8787/`
（报告里的音频链接按请求头自动推导，无需再手改 `base_url`）。

## 发布到公网（手机直接访问）

服务已按单端口托管形态改造，可直接发布：

| 配置项 | 取值 | 说明 |
|---|---|---|
| 监听 | `0.0.0.0:$PORT` | 读取 `PORT` 环境变量；未设置时用 8787 |
| 启动命令 | `python3 server.py` | 无第三方依赖，无需 install |
| 数据 | 项目内 `data/`、`output/` | JSON + 音频文件，随目录持久化 |
| 教师口令 | 环境变量 `TEACHER_KEY` > `teacher_key.txt` > 首次启动自动生成随机口令 | 写操作与名单、提交明细查询都需要 |

发布后是 **HTTPS 域名**，因此手机浏览器可以直接用网页录音（`getUserMedia` 要求安全上下文）；
本地用 `http://局域网IP` 访问时麦克风会被浏览器禁用，此时改用文件上传，后续链路完全相同。

运行环境缺少能力时的降级行为：

- **无 Chrome** → 报告自动出**网页版**（相对链接，手机可点开听音），页面内「打印 → 存储为 PDF」即可导出；
- **无本机 TTS** → 不再现场合成，直接使用仓库内已预置的示范音文件；缺文件时前端用浏览器语音朗读兜底；
- **无 afconvert/ffmpeg** → SOE 真实评测会明确报「转码失败」，不会用示例分数冒充真实结果。

> 源码里不含固定口令：未设置 `TEACHER_KEY` 且没有 `teacher_key.txt` 时，首次启动会自动生成随机口令，
> 写入 `data/teacher_key.txt`（已被 `.gitignore` 排除）并打印在启动日志。公网发布建议显式设置
> `TEACHER_KEY`，避免托管环境重启后口令变化；并按学校要求确认未成年人录音的授权与留存期限。


## 分享给其他老师 / 二次开发

先分清三种需求，做法完全不同：

| 想要的结果 | 怎么做 | 关键限制 |
|---|---|---|
| **只让别人用**（最快） | 把发布链接（带 `?sharecode=`）和教师口令发给对方 | 所有人共用**同一份数据、同一个班级、同一个教师口令**；拿到口令的人能改配置、生成演示数据、清空提交。学员端提交无需口令 |
| **让别人拿到源码、自己改自己跑** | 把整个 `zaodu/` 目录打包（或推到 Git 仓库）给对方；对方本地 `python3 server.py` 即可运行，或从自己那份目录重新发布，得到一个独立链接与独立数据 | 两份数据互不互通，改动也不会自动同步；要合并代码需走 Git |
| **多位老师共用一套系统、各管各的班** | 需要**再开发**：教师账号与登录、班级数据隔离、按角色的权限、持久化数据库（当前是项目内 JSON 文件） | 这是另一期工程，不是配置项能解决的；托管沙箱的文件存储也不保证长期持久 |

### 改功能改哪里

| 想改什么 | 文件 |
|---|---|
| 教师端/学员端界面、分页、按钮、批注交互 | `web/index.html`（单文件，含 CSS 与 JS；改完刷新浏览器即可，无需编译） |
| 接口、口令、分页逻辑、报告入参 | `server.py` |
| 报告版式、逐人批注、中文近似读音表 | `report.py`（`PHONEME_SAY` 中文近似、`PHONEME_TIPS` 改法话术、`build_html` 结构） |
| 评分规则、演示数据、SOE 对接 | `evaluate.py`、`media.py` |
| 字段、去重规则、名单归一化、批注存储 | `store.py` |
| 班级名称、材料、名单、截卡时间、权重 | `data/config.json`，或在教师端「任务配置」里改 |

改完 `server.py` / `report.py` / `store.py` 需要**重启服务**；若已发布到线上，还需从**同一个项目目录**重新发布一次，新链接才会生效（发布绑定的是目录，不是文件）。

> 安全与合规提醒：链接加口令不等于权限隔离；教师口令请单独告知、定期更换，别贴在群里。
> 学员录音属于未成年人个人信息，分享前确认监护人授权，并避免把同一个链接发给不相关的班级。


## 立刻看到完整效果

教师端点 **「生成演示数据」→「运行评测」→「生成 PDF 报告」**，会自动：
合成 4 条示例录音 → 生成最近 7 天 × 4 名学员的提交 → 评测 → 输出带「演示数据」水印的 PDF。

> 演示模式的分数与错音是**可复现的示例值**，不是真实发音评分。PDF 每份都带红色横幅声明；
> 一旦配置了真实密钥，会切换成 SOE 结果，水印自动消失。

## 文件结构

| 文件 | 职责 |
|---|---|
| `server.py` | HTTP 服务与全部 API，标准库 `ThreadingHTTPServer` |
| `store.py` | 配置 / 名单 / 提交记录的 JSON 存储、去重、音频留存清理 |
| `media.py` | 示范音合成（say→m4a）、SOE 所需 16k wav 转码、逐词 IPA 查询 |
| `evaluate.py` | 评测适配层：SOE 真实接口（TC3 签名）/ 演示模式、纠正话术生成 |
| `report.py` | 报告 HTML 版式 + Chrome 无头打印为 A4 PDF |
| `web/index.html` | 学员端 + 教师端 H5（手机网页可用） |
| `teacher_key.txt` | 教师口令（项目根或 `data/`；也可用环境变量 `TEACHER_KEY` 覆盖；两者都没有时自动生成） |
| `data/` | 运行时数据：`config.json`、`submissions.json`、`uploads/`、`audio/` |
| `output/` | 生成的报告（PDF；无 Chrome 时为 HTML） |

### 报告文件命名

| 报告类型 | 文件名示例 |
|---|---|
| 单个学生 | `张三-20261107读音纠正.pdf` |
| 批量合并 | `批量-20261107读音纠正-3人.pdf` |
| 全班 | `全班-20261107读音纠正.pdf` |
| 批量打包 | `批量-20261107读音纠正-3人.zip`（合并报告 + 每人单独报告） |

日期取**报告生成当天**（`YYYYMMDD`），姓名来自教师端配置的班级名单；查不到姓名时回退为
`学号<序号>`。同一天为同一学生重复生成会覆盖为最新版本；批量生成遇同名学生时，
第二份起自动追加 `-2`、`-3` 后缀避免互相覆盖。无 PDF 引擎时扩展名改为 `.html`，规则不变。
中文文件名通过 `filename*=UTF-8''...` 返回，浏览器下载/转发不会乱码。

## API

| 方法与路径 | 说明 |
|---|---|
| `GET /api/state` | 配置、名单、七日提交、运行状态、能力探测、报告列表 |
| `POST /api/config` | 保存任务配置 / 名单 / SOE 密钥（需口令） |
| `POST /api/submit` | 学员提交（音频为 base64），写文件并去重（学员端免口令） |
| `POST /api/evaluate` | 批量评测，`{"force":true}` 可重算（需口令） |
| `POST /api/report` | `{"days":7}` 生成全班报告；带 `"student_no":"01"` 只出该生批注单（需口令） |
| `POST /api/report_batch` | 勾选多名学生批量生成：合并报告 + 每人单独报告 + ZIP（需口令） |
| `POST /api/seed` | 生成可复现演示数据（需口令） |
| `POST /api/reset` | 清空提交记录（需口令） |
| `GET /api/submissions` | 全部提交明细（需口令） |
| `GET /api/submissions_page` | 提交记录分页（`page`/`size`/`q` 按序号姓名日期筛选，最新在前，需口令） |
| `POST /api/comment` | 保存教师批注（学员 + 任务日；留空保存＝删除），批注会写进报告（需口令） |
| `GET /audio/<name>` | 示范音与学员录音回放 |
| `GET /output/<name>` | 下载报告（PDF / HTML） |

教师口令通过请求头 `X-Teacher-Key` 传递，未带或错误返回 401；教师端页面输入一次后存于 `sessionStorage`。

## 接入真实评测（腾讯云智聆口语评测 SOE）

教师端勾选「启用 SOE」并填入 SecretId / SecretKey，或编辑 `data/config.json`：

```json
"soe": { "enabled": true, "secret_id": "AKID...", "secret_key": "..." }
```

实现依据官方文档：`TransmitOralProcessWithInit` / `2018-07-24`，
域名 `soe.tencentcloudapi.com`，TC3-HMAC-SHA256 签名，非流式一次性传输。
`eval_mode`：`0` 单词、`1` 句子；`server_type`：`0` 英文、`1` 中文。
音频会先由 `afconvert` 转成接口要求的 **16kHz / 16bit / 单声道 wav**（`VoiceFileType=2`）。

真实模式**评测失败不会静默降级成示例分数**，报告会标注失败原因，避免把假分当真分。

评分权重默认 `准确度 0.6 / 流利度 0.2 / 完整度 0.2`，音素分 < 60 判为需纠正。
这是**待校准的初值**，请用本班样本与教师人工听评比对后，在 `config.json` 的 `weights` 中固定。

## 已落地的设计规则

- 身份：沿用群里的「序号 + 姓名」作为学员 ID。`1` / `01` / 全角 `００１` 会统一归一化到名单写法
  （如 `01`），避免同一学员被拆成两条记录；不在名单内会被拒绝并提示当前名单。
- 截卡：默认 23:30（取自群名），过点关闭提交，补交由教师端处理；任务日按自然日归属。
- 去重：`(task_id, student_no)`，同人当天重复提交覆盖并保留历史版本。
- 报告：班级概览 / 七日提交矩阵 / 材料与示范音 / 逐词音标；
  **每位学员独立一页，固定三块**：① 一句话看懂（交几次、均分、最该改哪几个词）；
  ② 每天读得怎么样（综合/准确/流利/完整四项分 + 本人读音回放 + 当天读错的词）；
  ③ 错在哪 · 怎么读——每个错词一行：**「应当这样读」给出中文近似读音**（如 bird → 伯 · 厄— · 德，
  带长音符号要拖长）、错在第几个音、差多少分、一句可照做的改法；不认音标也能直接教。
  全班共性错音只放末页附录（附「怎么读」列）；纠正不跨日期、不跨学员合并。
  演示模式的错音只从该词音标里真实存在的音素中挑选，避免给 bird 安上 /θ/ 这类张冠李戴的批注。
- 隐私：音频按 `retention_days` 到期清理；报告仅教师可见，不做公开排名。
- 音标：内置常用词表 + 在线词典回填，查不到显示「待回填」，**不猜测音标**。

## 明确未做的部分（不要误判为已实现）

1. **读取微信聊天记录**：个人微信没有开放的聊天记录接口，且《腾讯微信软件许可及服务协议》
   8.2.1.6 与微信安全中心 2026-01 公告明确禁止第三方工具访问、读取、转储微信数据。
   本系统只接收**学员本人主动提交**的录音。群里已有的历史语音只能人工导出后从网页上传。
2. **微信扫码登录 / openid**：当前用序号 + 姓名标识。若已有认证公众号，可在 H5 加网页授权
   静默取 openid 免填；也可以在微信小程序里录音，兼容性更好。
3. **PDF 内嵌可播放音频**：PDF 里放的是可点击链接（需本地服务在线），并附短链文本。
   手机扫码听音需要再接二维码生成库。
4. **视频抽音轨 / webm 转码**：`afconvert` 支持 m4a/mp3/wav/mov，不支持 webm。
   Chrome 网页录音产生 webm 时，真实 SOE 评测会提示转码失败；生产环境需装 ffmpeg，
   或让录音优先落到 mp4（微信内 iOS 即如此）。
5. **多班级 / 账号体系**：仍是单班应用，只有一个教师口令，没有分用户登录与权限分级；
   已支持公网发布（单端口 + 项目内文件存储），但托管环境的磁盘是否为持久卷需与平台确认，
   重要数据请定期导出 `data/` 备份。
6. **评分模型校准**：机器分与教师人工听评的一致性尚未用真实样本验证。

## 常见问题：麦克风 Permission denied

浏览器拒绝 `getUserMedia` 时会显示这个提示，常见于三种情况：内置预览面板不给麦克风权限、
站点权限曾被点「拒绝」、手机用 `http://局域网IP` 访问（非安全上下文，浏览器直接禁用录音）。

**不影响使用**：点「选择语音 / 视频文件（推荐）」上传录音即可，后续评测、报告链路完全相同；
手机上可点「手机直接录一段」调起系统录音再上传。实测 m4a 上传 → 提交 → 评测 → 音频回放全通。

若确实需要网页内直接录音：用系统浏览器打开 `http://127.0.0.1:8787/`，在地址栏站点权限里允许麦克风，
并确认 macOS「系统设置 → 隐私与安全性 → 麦克风」已授权给该浏览器；手机经局域网访问则需为服务配置 HTTPS
（自签证书需在手机上信任）。Chrome 网页录音产生 webm，真实 SOE 评测还需 ffmpeg 转码，见上文限制 4。

## 上传到 GitHub（公开仓库安全须知）

仓库已自带 `.gitignore`，**下列内容不会入库**：教师口令 `teacher_key.txt`、
含 SOE 密钥的 `data/config.json`、学员提交 `submissions.json`、教师批注 `comments.json`、
录音 `data/uploads/`、生成的报告 `output/`、缓存与临时文件。

首次运行前：

```bash
cp data/config.example.json data/config.json   # 可选：不改则用内置默认配置
export TEACHER_KEY='你自己的口令'              # 不设置则首次启动自动生成随机口令并打印
python3 server.py
```

推送（**GitHub 已不支持账号密码，必须用 Personal Access Token 或 SSH Key**）：

```bash
git init && git add . && git commit -m "早读语音评测系统：可运行源码"
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
```

若仓库公开，请勿提交任何真实学员名单、录音、密钥或教师口令。
